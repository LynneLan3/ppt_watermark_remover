# SOP 候选规则

> 从开发过程中发现的经验，待验证后升级到 SOP
> 规则：一次经验 → 记录；两次重复 → 考虑升级；影响成败 → 必须升级

---

## 候选规则列表

### structureDense 页面 micro seam 放行门槛

- **来源**: v6 light_complex seam micro polish 回归（2026-04-25）
- **发现时间**: 2026-04-25
- **验证次数**: 1
- **内容**: 对 `structureDense=true` 页面，seam 微调必须满足“seam 显著下降且 residual/texture/brightness 零反弹”，否则统一回滚。
- **建议**: 暂不升级（需至少再验证 1-2 次）

### Beta 用户流下载门控绑定 preview ready

- **来源**: Beta 上线准备（免费预览确认模式，2026-04-25）
- **发现时间**: 2026-04-25
- **验证次数**: 1
- **内容**: 正式用户流应以“cleaned 预览渲染成功”作为下载按钮可用前提，避免用户在未看结果时直接下载。
- **建议**: 暂不升级（需在更多样本和线上反馈中复验）

### 反馈闭环先落盘 JSONL 再升级数据库

- **来源**: Beta 上线准备（用户反馈入口，2026-04-25）
- **发现时间**: 2026-04-25
- **验证次数**: 1
- **内容**: Beta 初期可将每页反馈以 `tmp/user-feedback/{jobId}.jsonl` 落盘（jobId/page/feedbackType/note/algorithmProfile），降低上线复杂度并保留后续聚合空间。
- **建议**: 暂不升级（需验证数据量与分析流程稳定性）

### 双栏预览必须共享页码并禁止单侧自动跳页

- **来源**: 首页主流程与预览一致性修复（2026-04-26）
- **发现时间**: 2026-04-26
- **验证次数**: 1
- **内容**: 左右 PDF 预览必须共享 `currentPage` 与统一 `totalPages`；若 cleaned 侧该页不存在，只允许显示明确 placeholder，禁止回退到其它页造成“看起来有图但页码错位”。
- **建议**: 暂不升级（需在更多真实样本复验）

### 下载门控需要三条件并且与状态机绑定

- **来源**: 首页主流程与预览一致性修复（2026-04-26）
- **发现时间**: 2026-04-26
- **验证次数**: 1
- **内容**: `Download cleaned PDF` 仅在 `job.status === ready_for_download`、`cleanedPdfUrl` 存在、`processed preview` 可渲染时可点击，处理中必须强制禁用。
- **建议**: 暂不升级（需线上反馈复验）

### processed 页数与 original 不一致必须失败并禁用下载

- **来源**: 失败态半成品隔离修复（2026-04-26）
- **发现时间**: 2026-04-26
- **验证次数**: 1
- **内容**: 处理后若 `processedPageCount !== originalPageCount`，状态必须进入 `failed` 或 `partial_failed`，前端禁止 cleaned 下载与成功预览，错误文案需明确提示“未完整处理全部页面”。
- **建议**: 暂不升级（需更多样本复验）

### Python 输出文件采用 tmp 到正式文件的原子替换

- **来源**: 失败态半成品隔离修复（2026-04-26）
- **发现时间**: 2026-04-26
- **验证次数**: 1
- **内容**: Python 处理输出应先写 `processed.tmp.pdf`，完成并通过页数校验后再 rename 为 `processed.pdf`；失败时删除 tmp，必要时落 `processed.partial.pdf` 仅供排障，前端不得使用 partial。
- **建议**: 暂不升级（需跨脚本复验）

### 正式用户路径默认不展示 Page feedback

- **来源**: 前端页面收口（2026-04-26）
- **发现时间**: 2026-04-26
- **验证次数**: 1
- **内容**: `Page feedback` 区块默认不在正式页面渲染，仅在 `?debug=1` 或 `NEXT_PUBLIC_ENABLE_INTERNAL_REVIEW=true` 条件下显示，避免主流程噪音。
- **建议**: 暂不升级（需线上复验）

### 首页上传 CTA 统一锚点跳转

- **来源**: 前端页面收口（2026-04-26）
- **发现时间**: 2026-04-26
- **验证次数**: 1
- **内容**: “Start from homepage upload” 需统一跳转 `/#homepage-upload`，并确保首页主上传卡具备对应 id，避免用户仅回到页面顶部。
- **建议**: 暂不升级（需跨页面复验）
